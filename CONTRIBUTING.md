# Contribuindo

Obrigado por querer ajudar. Algumas combinações para a contribuição chegar
rápido ao projeto:

1. **Abra uma issue antes** de mudanças grandes, para alinhar a abordagem.
2. **Siga [docs/desenvolvimento.md](docs/desenvolvimento.md)** para rodar e
   testar. O pull request precisa passar no CI (testes Go com Postgres real,
   testes e build da tela).
3. **Teste que falharia sem a mudança.** Correção de bug vem com o teste que
   reproduz o bug.
4. **Sem dados reais** em issues, testes ou exemplos: nada de CNPJ, telefone
   ou e-mail de empresa de verdade. Use o seed de teste ou o modo
   demonstração.
5. **Português** em código, comentários, commits e documentação.

Problemas de segurança não vão para issue pública: veja [SECURITY.md](SECURITY.md).
